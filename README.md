# AI Tic-Tac-Toe

## Project Overview

This is a browser-based Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.

## Features

* User vs AI gameplay
* Minimax Algorithm for optimal AI moves
* Win detection
* Draw detection
* Restart game option
* Interactive web interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download the project files.
2. Open `index.html` in a web browser.
3. Play against the AI.

## AI Algorithm

The project uses the Minimax algorithm, which evaluates possible future moves and selects the optimal move for the AI player.
