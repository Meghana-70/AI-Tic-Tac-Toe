# AI Tic-Tac-Toe

## Project Overview

This is a browser-based Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.

## Features

* User vs AI gameplay
* Minimax Algorithm for optimal AI moves
* Win detection
* Draw detection
* Restart game option
* Interactive web interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download the project files.
2. Open `index.html` in a web browser.
3. Play against the AI.

## AI Algorithm

AI uses the Minimax algorithm, which is a standard approach for optimal Tic-Tac-Toe play and helps explain why the computer is difficult to beat. Perfect-play Tic-Tac-Toe AIs are designed to avoid losing and typically force a draw or capitalize on mistakes.
